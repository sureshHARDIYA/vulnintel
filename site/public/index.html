Quick start

Install Rust and clone the repository. Query a specific package/version using the CLI:

cargo run -p vulnintel-cli -- match npm lodash 4.17.20

View the README for installation, configuration and library usage.

Data: public GitHub advisories and CISA KEV. Not comprehensive; always consult original advisories and confirm actual installed versions. No tracking or analytics.
